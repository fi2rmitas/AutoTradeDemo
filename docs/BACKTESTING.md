# 과거 가격 백테스트 안내

## 시작 방법

백테스팅 메뉴에서 보관 시세 또는 직접 준비한 CSV를 불러옵니다. CSV는 외부 서버에 업로드하지 않습니다. 브라우저가 읽고 검증한 다음 독립 계산 작업에서 처리합니다. 관제의 가상 계좌·주문·전략 실행 여부와 독립적입니다.

이 PC의 229200 보관 시세는 기존 프로젝트에서 과거에 조회한 일봉입니다. 원본 해시와 복사본이 일치하는지 확인했으며 브라우저에서도 해시와 행 수·시작/종료일을 대조합니다. 이것은 파일 무결성 검사이며 시세 정확성이나 거래소 달력의 완전성 인증은 아닙니다. 원 프로젝트에는 다른 출처와 가격을 대조한 기록이 있지만 거래량 차이 원인은 미확정입니다. 이번 전략들은 거래량을 신호에 사용하지 않습니다.

## CSV 형식

한 파일에 한 종목을 넣습니다. 최소 열은 date와 close입니다. 다음 거래일 시가 체결을 하려면 open을 넣어야 합니다. high·low·volume은 선택 항목이며 제공하면 검증합니다.

```csv
date,open,high,low,close,volume
2024-01-02,10000,10200,9900,10100,20000
2024-01-03,10100,10300,10000,10200,18000
```

위 두 행은 형식 설명용 가상 값이며 실제 분석에는 지표 준비 기간과 분석 기간을 포함한 더 긴 데이터가 필요합니다. 화면의 형식 예제는 전체 가상 시계열을 내려주며 `data_kind=synthetic` 표식을 보존합니다. 이 파일을 다시 불러와도 가상 데이터로 표시됩니다.

- 영문 date/open/high/low/close/volume, 한글 일자·날짜·시가·고가·저가·종가·거래량을 지원합니다.
- 날짜는 YYYY-MM-DD, YYYYMMDD, YYYY/MM/DD, YYYY.MM.DD입니다. 월·일은 두 자리여야 합니다.
- UTF-8(BOM 포함)과 CP949, 쉼표 CSV·탭 구분·세미콜론 구분을 지원합니다.
- 천 단위 쉼표가 있는 값은 `"10,000"`처럼 따옴표로 감쌉니다.
- symbol 또는 종목코드 열이 있으면 모든 행이 동일한 종목이어야 합니다. 입력한 코드와도 일치해야 합니다. 국내 숫자 코드는 6자리로 정규화합니다.
- 중복 날짜·주말 행·유효하지 않은 날짜·0 이하 가격·비숫자·잘못된 OHLC·열 수 오류는 거부합니다. 거래정지로 0원 OHLC가 포함된 파일은 원 자료를 확인한 뒤 별도로 정제해야 합니다. 자동 삭제나 가격 보간은 하지 않습니다.
- 역순은 과거→최근 순으로 정렬하고 알립니다. 10일 초과 공백은 경고합니다. 경고가 없다고 휴장일 대조가 완료된 것은 아닙니다.
- 별도의 Adj Close/수정종가 열은 적용하지 않습니다. 종가와 OHLC의 조정 기준을 동일하게 준비하세요. 사용자가 선택한 조정 여부는 출처 설명이며 자동 인증하지 않습니다.
- 입력 파일은 최대 20MB·10만 행입니다. 데이터와 결과는 새로고침 전에 CSV/JSON으로 저장하세요.

새 자료는 제공처에서 내려받은 일별 시세 CSV를 사용할 수 있습니다. [KRX 데이터 포털](https://data.krx.co.kr/contents/MDC/MAIN/main/index.cmd?vsView=Y)의 주식·ETF 개별종목 시세 추이 메뉴를 참고할 수 있습니다. 사용 권한과 원본 가격 조정 설정은 자료 제공처에서 확인하고 출처 입력란에 기록하세요. 앱이 이 사이트나 증권사 API를 자동 호출하지 않습니다.

## 기존 전략 기준

기본은 코스닥150 ETF인 KODEX 코스닥150(229200)의 삼중 모멘텀입니다. 신호 가격과 매매 가격 모두 229200 원주가 종가를 사용한 기존 Python 구현을 기준으로 합니다. 기본 조건은 전체 데이터 기간·초기 1천만원·기준선 4%·진입 비중 100%·편도 수수료 0.015%·슬리피지 0.05%·매도세 0%·다음 거래일 종가 체결입니다. 나머지 전략과 시가 체결은 비교용입니다.

## 전략과 체결 시점

| 전략 | 진입 | 청산 | 시작일 앞 준비 행 |
|---|---|---|---|
| 이동평균 모멘텀 | 전일 단기 평균 > 장기 평균 | 단기 평균 < 장기 평균 | 장기 기간 |
| 평균 회귀 | 전일 종가 < 장기 평균 × 0.975 | 전일 종가 ≥ 장기 평균 | 장기 기간 |
| 종가 돌파 | 전일 종가 > 그 앞선 장기 기간 최고 종가 | 전일 종가 < 장기 평균 | 장기 기간 + 1 |
| 삼중 모멘텀 | ROC(5)+ROC(15)+ROC(25)가 기준선을 새로 상향 돌파 | 기준선을 새로 하향 이탈 | 초기 26행은 기간 내 현금 보유로 포함 가능 |

ROC(n)은 `(현재 종가 / n거래일 전 종가 - 1) × 100`입니다. 삼중 모멘텀은 처음부터 기준선 위에 있다는 이유만으로 매수하지 않으며 새 돌파만 처리합니다. 다른 세 전략은 시작일 이전 데이터의 상태 조건이 성립하면 분석 첫 거래일에 진입할 수 있습니다. 평균이 같으면 SMA 전략은 현재 포지션을 유지합니다.

신호는 체결일 이전 거래일까지의 종가만 사용합니다. 기본 체결가는 원본과 같은 다음 거래일 종가입니다. 시가 체결은 명시적으로 선택하는 비교용 모드입니다. 마지막 거래일의 신호를 가상의 다음 거래일에 체결하지 않습니다. 기간이 CSV 범위를 벗어나면 임의로 잘라 계산하지 않고 오류를 표시합니다. 삼중 모멘텀은 상장일부터 분석할 때 초기 준비 구간을 현금 보유일로 포함합니다. 분석 시작일 이전에 발생한 신호는 체결하지 않습니다. 비교용 세 전략은 시작일 앞 준비 자료가 부족하면 오류를 표시합니다.

## 비용과 장부

- 매수 체결가 = 기준가 × (1 + 슬리피지/100)
- 매도 체결가 = 기준가 × (1 - 슬리피지/100)
- 진입 수량 = 내림(현재 현금 × 진입 비중 / [매수 체결가 × (1 + 수수료/100)])
- 매수 수수료 = 매수 금액 × 편도 수수료/100
- 매도 수수료·매도세 = 매도 체결 금액 × 각각의 비율/100
- 매도 실현손익 = 매도대금 - 매도 수수료 - 매도세 - 매수 원가(매수 수수료 포함)
- 일별 평가자산 = 현금 + 보유 수량 × 그날 종가

정수 주 수량, 전량 매도, 한 번에 한 포지션을 사용합니다. 추가 매수·공매도·신용·호가 단위 반올림·실제 호가 및 거래량 제약은 없습니다. 계산값은 부동소수점으로 보존하고 화면은 원 단위로 반올림합니다. CSV·JSON은 계산값을 보존합니다.

매도세 기본값 0%는 세금 면제 판정이 아닙니다. 종목과 시기에 맞는 가정을 사용자가 입력해야 합니다. 배당·분배금·이자·기업행사 현금흐름은 제외합니다. 원주가의 분배락·권리락·분할은 신호에 영향을 줄 수 있습니다. 종료 시 보유분을 종가로 평가하며 강제 매도하거나 청산 비용을 가정하지 않습니다.

## 비교와 지표

매수 후 보유는 분석 첫 거래일에 같은 종목·체결 기준·자금·진입 비중·매수 수수료·슬리피지로 진입합니다. 남은 현금과 마지막 보유분도 전략과 동일하게 평가합니다. 기간 말에 매도하지 않으므로 청산세와 매도 수수료가 발생하지 않습니다.

누적 수익률은 초기 자금 대비 최종 평가자산 변화입니다. CAGR은 첫 분석 거래일부터 마지막 거래일까지의 달력 일수/365.25를 기준으로 연율화합니다. 짧은 기간의 CAGR은 과장될 수 있고 표현 범위를 넘으면 수치를 표시하지 않습니다.

최대 낙폭은 초기 자금을 포함한 일별 종가 평가자산의 이전 최고점 대비 하락률입니다. 일중 최대 손실을 뜻하지 않습니다. 승률은 모든 비용을 뺀 청산 거래의 흑자 비율이며 미청산 거래는 제외합니다. Profit factor는 이익 청산 합계 / 손실 청산 절댓값 합계입니다. 손실 청산이 없으면 무한대 대신 표시를 생략합니다.

## 내보내기와 재현

자산곡선 CSV에는 날짜, 전략 자산, 매수 후 보유 자산, 현금, 수량, 낙폭을 기록합니다. 체결 CSV에는 체결일·신호일·수량·기준가·체결가·수수료·세금·슬리피지·현금·보유 수량·실현손익을 기록합니다.

JSON에는 스키마와 엔진 버전, 실제 계산 기간, 전체 설정, 데이터 출처·조정 상태·SHA-256, 모든 일별 결과와 체결을 저장합니다. 동일 CSV와 같은 엔진·설정이면 결과가 같습니다. 화면 차트만 최대 약 500점으로 축약하며 첫·끝과 각 구간의 극값을 보존합니다. 내보낸 원장은 축약하지 않습니다.

계산은 Web Worker에서 실행합니다. 계산 중단은 계산 작업만 종료하며 가상 관제 주문을 변경하지 않습니다. 조건을 바꿨을 때 이전 결과에는 다시 계산해야 한다는 표시가 붙습니다. 입력 실패 시 이전 데이터나 결과가 자동으로 다른 자료로 바뀌지 않습니다.

## 검증 범위

새 테스트 28개와 기존 회귀 테스트 15개가 통과했습니다. 수기로 확인 가능한 수수료·슬리피지·세금 장부, 현금/수량 일치, 미래 가격 변경 시 이전 체결 불변, 전략별 신호 시점, 준비 기간, CSV 오류, 가상 예제 표식, 차트 축약을 검사합니다.

현재는 단일 종목의 가격 기준 연구 도구입니다. 총수익 자료, 전체 거래 달력, 거래정지·상장폐지·기업행사·거래량·호가 단위, 다중 종목·동시성, 대규모 원장 영구 저장은 후속 과제입니다.
