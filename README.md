# Stock Auto Trader v0.1

React + TypeScript 기반의 반응형 국내 주식 자동매매 관제 데모입니다. 모든 가격·계좌·성과·주문은 가상 데이터이며 실제 증권사 API, 인증키, 실주문 기능은 없습니다.

## 실행

Node.js 22.12 이상과 npm이 있는 환경에서:

```powershell
git clone https://github.com/fi2rmitas/AutoTradeDemo.git
cd AutoTradeDemo
# 구현 PR이 병합되기 전에는 아래 브랜치를 선택합니다.
git switch codex/stock-auto-trader-v0.1
npm install
npm run dev
```

화면에 표시되는 로컬 주소를 엽니다. 기본 주소는 `http://127.0.0.1:5173/`입니다. 실행 창에서 `Ctrl+C`를 누르면 서버가 종료됩니다.

```powershell
npm test
npm run build
npm run preview
```

고정된 의존성으로 재현하려면 pnpm 11.25.0에서 `pnpm install --frozen-lockfile`을 사용합니다. `pnpm-lock.yaml`은 검증에 사용한 버전을 고정합니다. pnpm 11의 esbuild 설치 스크립트는 `pnpm-workspace.yaml`에 명시적으로 허용했습니다. npm은 pnpm 잠금 파일을 사용하지 않습니다.

Windows에서는 의존성 설치 후 `Build-Dashboard.cmd`로 빌드하고 `Start-Dashboard.cmd`로 실행할 수 있습니다. `Test-Dashboard.cmd`는 테스트를 실행합니다. 실행 파일은 PATH의 Node.js 또는 설치돼 있는 Codex Node 런타임을 사용합니다. `Start-Dashboard.cmd`는 빌드한 `dist/`를 127.0.0.1:5173에서 제공합니다. 이 포트를 다른 앱이 사용 중이면 먼저 해당 앱을 종료하세요.

Git 저장소에는 node_modules와 dist를 넣지 않습니다. 소스를 받은 뒤 설치와 빌드를 먼저 실행하세요.

## 기능

- 좌측 메뉴와 모바일 접이식 메뉴, 모의계좌·시장·통화 표시
- 총 평가자산, 일간 손익, 누적 손익, 예약 현금을 제외한 주문 가능 금액
- 자산곡선 / 수익률 비교 탭, 기간 선택, 국내 주식·현금 자산 구성
- 3개 전략의 실행·일시정지, 3주 가상 주문 시뮬레이션
- 보유 종목 검색, 수량·평균단가·평가손익·비중 표시
- 가상 매수·매도, 체결, 취소, 상태 필터, 주문 내역 CSV
- 일일 손실·주문 금액·종목 비중 한도 저장 및 주문·체결 시 재검증
- 미체결 주문의 예약 현금·예약 매도 수량 반영
- 긴급 중지, 확인창, 미체결 주문 취소, 신규 주문·체결 차단
- 시스템 상태, 활동 로그, 초기 가상 장부 복원
- 독립 백테스팅: 전략·기간·초기 자금·수수료·슬리피지 설정, 차트와 지표, 시계열 CSV
- 새로고침 시 로컬 장부와 긴급 중지 상태 복원

긴급 중지는 모든 전략을 정지하고 미체결 가상 주문을 취소합니다. 보유 종목을 매도하지 않습니다. 해제 후에도 전략은 직접 시작해야 합니다. 개별 전략 일시정지는 신규 주문 생성을 막으며 기존 대기 주문을 자동 취소하지 않습니다.

## 시뮬레이션 규칙

관제 화면은 2026-10-27 기준으로 만든 고정 가상 시나리오입니다. 현재 시세나 실제 장 운영 상태가 아닙니다. 전략 실행 상태는 관제용 가상 상태이며 백그라운드 자동 주문 루프는 없습니다.

초기 자금은 3,000만원, 평가자산은 3,350만원, 현금은 854만원입니다. 초기 실현손익 235만원과 평가손익 115만원이 누적 수익 350만원을 구성합니다. 예시 체결 2건은 초기 장부에 이미 반영한 과거 내역입니다. 일간 비교 기준 자산은 33,228,000원입니다.

체결은 고정 가상 시세로 처리합니다. 매수 시 가중평균 단가를 갱신하고, 매도 시 실현손익에 반영합니다. 관제 장부 수수료·세금은 0원입니다. 자산곡선·가상 KOSPI·전략별 성과는 화면 예시이며 실제 과거 기록이나 독립 백테스트 결과가 아닙니다.

위험 한도 변경은 이후 주문과 체결부터 적용합니다. 기존 보유분을 강제 매도하지 않습니다. 종목 비중 한도 초과 시 경고가 표시됩니다. 일일 손실 한도에 도달하면 신규 주문과 체결을 차단합니다.

상태는 브라우저의 localStorage에 저장됩니다. 여러 탭의 동시 편집을 동기화하는 서버는 없습니다. 저장 공간 제한 시 화면에서 알리고, 손상되거나 버전이 맞지 않는 저장 값은 초기값으로 복원합니다.

## 독립 백테스트

2024-01-01~2026-10-27 범위의 결정적 합성 평일 시계열을 사용합니다. 한국 휴장일과 특정 실제 종목을 반영하지 않습니다. v0.1의 예시 규칙은 다음과 같습니다.

| 전략 | 진입 | 청산 |
|---|---|---|
| 모멘텀 | 이전 거래일까지의 SMA 5 > SMA 20 | SMA 5 < SMA 20 |
| 평균 회귀 | 전일 종가가 20일 평균보다 2.5% 낮음 | 전일 종가가 20일 평균을 회복 |
| 돌파 | 전일 종가가 이전 19거래일 최고 종가 이상 | 전일 종가가 20일 평균을 하회 |

관제 전략의 정식 구현은 아닙니다. 신호는 이전 거래일까지의 데이터로 계산하고 다음 합성 종가에 체결합니다. 진입·청산 양쪽에 편도 수수료와 슬리피지를 적용합니다. 세금·배당·공매도·환율은 제외하며 마지막 보유분은 평가합니다. 매매 횟수는 매수·매도를 각각 세고, 승률은 청산한 거래만 계산합니다. 합성 데이터 결과는 실제 투자 성과를 의미하지 않습니다.

## 검증

TypeScript 검사, Vite 프로덕션 빌드, 핵심 테스트 15개를 통과했습니다. 로컬 HTTP 응답, PC·모바일 화면, 차트 탭, 전략 정지, 가상 주문 생성·체결, 보유 수량 변경, 위험 한도 차단, 긴급 중지·복원·해제, 독립 백테스트, CSV 내려받기를 확인했습니다.

## 개발 상태와 다음 작업

AutoTradeDemo는 파일·브랜치·커밋이 없는 상태에서 확인한 저장소입니다. main의 소개 문서와 별도 `codex/stock-auto-trader-v0.1` 브랜치를 통해 첫 구현을 검토합니다. 이전에 작성한 로컬 프로그램과 개인 설정은 보존했으며 이 데모와 연결하지 않았습니다.

다음 작업은 검토한 구현의 main 병합, 화면 컴포넌트 파일 분리와 라우팅, 정식 전략 및 공통 엔진 연결, 이력 저장소와 동시성 처리, 검증된 과거 데이터·거래 달력·세금·기업행사, 긴 작업용 백테스트 워커, 미국 주식·다중 통화 확장입니다. 증권사 API와 실주문은 이번 버전의 범위에 포함하지 않습니다.
