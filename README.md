# Stock Auto Trader v0.2.1

React + TypeScript 기반 국내 주식 관제 데모와 과거 가격 CSV 백테스터입니다. 관제 계좌·주문은 가상이며, 백테스트는 사용자가 불러온 가격 자료로 독립 계산합니다. 실제 증권사 API·인증키·실주문 기능은 연결하지 않습니다.

## 현재 PC에서 실행

1. `Start-Dashboard.cmd`를 실행합니다. 이미 실행 중이면 브라우저를 새로고침합니다.
2. `http://127.0.0.1:5173/`에서 **백테스팅** 메뉴를 엽니다.
3. **이 PC 보관 시세 · 229200**을 누르거나 과거 가격 CSV를 선택합니다.
4. 전략·기간·비용을 확인하고 **백테스트 계산**을 누릅니다.
5. 자산곡선, 낙폭, 체결 원장을 확인하고 CSV 또는 JSON으로 저장합니다.

현재 PC에는 기존 프로젝트의 보관 CSV를 별도 복사한 로컬 캐시가 있습니다. 원본 CSV와 메타데이터는 수정하지 않았습니다. 캐시는 KODEX 코스닥150(229200), 2015-10-01~2026-10-02, 2,699행이며 기존 메타데이터의 SHA-256과 일치합니다. 출처는 과거 키움 REST 모의 서버 조회 기록이며 원주가입니다. 최신 시세가 아니고, 거래소 원본·전체 휴장일·기업행사·분배금의 완전성을 재검증한 자료는 아닙니다. 브라우저가 캐시를 읽는 과정에서는 증권사에 접속하지 않습니다.

로컬 가격 캐시 `public/local-data/`는 Git에서 제외합니다. 저장소를 새로 받은 PC에는 이 자료가 없으므로 CSV를 직접 불러오세요. **가상 예제로 연습**은 명시적으로 선택해야 하며 실제 가격 자료를 대신해 자동 실행하지 않습니다.

## 저장소에서 실행

Node.js 22.12 이상과 npm이 있는 환경에서:

```powershell
git clone --branch codex/historical-backtesting https://github.com/fi2rmitas/AutoTradeDemo.git
cd AutoTradeDemo
npm install
npm run dev
```

```powershell
npm test
npm run build
npm run preview
```

의존성을 고정해 재현하려면 pnpm 11.25.0에서 `pnpm install --frozen-lockfile`을 사용합니다. npm은 pnpm 잠금 파일을 사용하지 않습니다. 이번 변경에는 추가 패키지가 없습니다.

Windows 실행 파일은 PATH의 Node.js 또는 설치된 Codex Node 런타임을 사용합니다. `Build-Dashboard.cmd`는 타입 검사와 빌드, `Test-Dashboard.cmd`는 테스트, `Start-Dashboard.cmd`는 빌드한 dist를 127.0.0.1:5173에서 제공합니다. 다른 앱이 이 포트를 사용하면 먼저 사용 중인 앱을 확인하세요. 직접 실행 파일을 더블클릭해 여는 대신 HTTP 서버로 접속해야 Web Worker와 파일 검증이 동작합니다.

## 기존 전략과 기본 조건

주 전략은 **KODEX 코스닥150(229200)의 종가로 계산하는 삼중 모멘텀**입니다. 나스닥 시세나 코스닥 종합지수를 사용하지 않습니다. ROC(5)+ROC(15)+ROC(25)가 +4%를 새로 상향 돌파하면 매수, 하향 이탈하면 매도하며 다음 ETF 거래일 종가에 체결합니다. 기본값은 초기 1천만원, 진입 비중 100%, 편도 수수료 0.015%, 슬리피지 0.05%, 매도세 0%, 데이터 전체 기간입니다. 분석 시작일 이전 신호는 체결하지 않으며 초기 지표 준비 구간도 현금 보유일로 평가합니다.

다른 세 전략과 시가 체결은 비교용 선택지입니다. 기존 결과를 재현할 때는 **기존 전략 조건 적용**을 누릅니다. 기존 Python 코드와의 대조 결과는 [원본 전략 재현](docs/ORIGINAL_STRATEGY.md)에 있습니다.

## 백테스트 기능

- UTF-8·CP949 CSV, 한글·영문 헤더, 천 단위 쉼표, 역순 가격 지원
- 날짜·중복·유한 가격·OHLC 범위·단일 종목 검증, 누락 의심 구간 경고
- 기본은 다음 거래일 종가 체결. 시가 체결은 별도 비교용 선택
- 이동평균 모멘텀, 평균 회귀, 종가 돌파, 삼중 모멘텀 ROC 5/15/25
- 초기 자금, 진입 비중, 수수료, 슬리피지, 매도세, 평균 기간·기준선 설정
- 전일 신호와 다음 거래일 체결 구분, 정수 수량과 현금 장부 검산
- 동일 종목·비중·비용의 매수 후 보유 비교, 수익률·CAGR·낙폭·승률·총이익/총손실
- 자산·낙폭 차트, 체결 원장, 자산곡선 CSV·체결 CSV·설정/결과 JSON
- 별도 Web Worker 계산과 취소, 대량 차트만 축약하고 원본 결과는 보존
- 출처·가격 조정 기준·파일 해시·실행 조건을 결과에 기록

입력 CSV와 결과는 브라우저 메모리에만 보관하며 새로고침하면 다시 불러와야 합니다. 메뉴를 오가는 동안에는 유지됩니다. 관제 계좌·위험관리·긴급 중지 상태는 기존처럼 localStorage에 별도 저장됩니다.

## 관제 데모

기존 v0.1의 계좌 카드, 성과 탭, 전략 실행/일시정지, 종목 검색, 가상 매수·매도·체결·취소, 예약 현금/수량, 위험 한도, 긴급 중지, 활동 로그를 유지했습니다. 관제 시나리오는 2026-10-27 기준 고정 예시이며 실제 현재 시세가 아닙니다. 관제 전략 카드의 성과는 백테스트 결과와 별개입니다. 긴급 중지는 보유분을 매도하지 않으며 해제 후 전략은 직접 시작해야 합니다.

v0.1 합성 백테스트 함수와 회귀 테스트도 보존했습니다. 새 백테스트는 관제 모의계좌 잔액을 사용하거나 변경하지 않습니다.
